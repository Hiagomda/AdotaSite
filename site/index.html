            Dúvidas comuns

            O Android mostrou um aviso. É seguro?

            Sim, desde que tu baixes daqui. Este é o arquivo oficial, o mesmo que a equipe publica a cada versão. O Android mostra esse aviso para todo app baixado pelo navegador.

            Tem para iPhone?

            Ainda não. Por enquanto o app é só para Android.

            Como atualizo o app?

            Ao abrir, o app confere se tem versão nova e te avisa. Também dá para baixar aqui por cima da versão instalada, sem perder nada.

            Apareceu “app não instalado”. E agora?

            Confere se tem espaço livre no celular e se o download terminou. Se continuar, desinstala a versão antiga e instala de novo.

            Quanto custa?

            Nada. O app é grátis e nunca recebe dinheiro: as doações vão direto para quem cuida dos bichos.
